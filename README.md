Xashbox is **entity spawn** menu for Half-Life which uses **Entity Tools** feature from [Xash3D FWGS](https://github.com/FWGS/xash3d-fwgs) & [Axion-Client](https://github.com/Elinsrc/Axion) but on imgui.

# Download

   With Linux & Termux
```shell
git clone https://github.com/wh1tesh1t/xashbox/tree/imgui
cd xashbox
cp -r */ ../YOUR_GAME_DIRECTORY
```
or
```shell
mv */ ../YOUR_GAME_DIRECTORY/custom
```

### How I can use this?

   You must make a touch button with the command
```
exec_menu imgui
```
